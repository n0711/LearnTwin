# LearnTwin product scope

Updated 19 October 2026.

## The product today

A browser-local degree, study and PhD-application planner. The planner is on `main`, following PR #5. Courses, tasks and application requirements are entered by the user. Exported backups contain personal information; keep them private.

The MIT-licensed software remains free. There is no hosted subscription, official degree-audit integration, automated university application, funding prediction or admissions guarantee. The classroom prototype is separate and is not a production multi-user school service.

## Optional service to validate

Before building paid software features, test whether users want a one-off setup session: install or launch the planner, enter the user's own course requirements, configure a weekly workflow, and demonstrate export/import. Any fee would cover assistance, not access to the open-source code or an academic outcome. No paid offer or payment system is activated by this document.

Use screen sharing and let the user enter private records. Do not request university credentials or retain transcripts. Customisation for an adviser requires a separately scoped project and a review of data access before real student records are used.

## Evidence before expansion

Ask three independent students to complete first setup, enter a task, export a backup and return one week later. Record completion, time and reported problems without collecting their records. A useful signal is repeated use and an explicit request for paid help, not just a positive reaction to a demo.

Only consider cloud accounts or subscriptions after identifying a repeated need that local storage cannot serve and covering authentication, access isolation, backup, deletion and support costs.
